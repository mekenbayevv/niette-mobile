# NIETTE · мобильный кабинет

Фронтенд мобильного кабинета. Данные берёт из Apps Script (адрес в `API_URL`
внутри `index.html`); сам по себе ничего не хранит и секретов не содержит.

- `index.html` — приложение целиком
- `manifest.json`, `sw.js`, `icons/` — PWA-обвязка

Публикация и проверка: `GITHUB_PAGES_RUNBOOK.md` в основном проекте.
